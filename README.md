EventMini — Cadastro e Cálculo de Inscrições

Aplicação web simples para cadastrar participantes de um evento e calcular o valor das inscrições com desconto para estudantes.

Como executar na sua máquina
Clone ou baixe o repositório.
Abra o arquivo index.html diretamente no navegador (ou use a extensão Live Server no VS Code).
Regras esperadas do sistema
Valor base da inscrição: R$ 100,00.
Idade mínima: 16 anos.
Desconto de estudante: 20% sobre o valor base (ex.: R$ 100,00 com 20% de desconto = R$ 80,00).
Total arrecadado: deve somar o valor final de todos os inscritos confirmados e atualizar sempre que alguém for adicionado.
